# marketing-media

Archive of **marketing / brand / media assets that are NOT shipped** with the
app or website.

Files were moved here from `static/` because nothing in the codebase
references them (`node scripts/find-unused-media.mjs` audits this), and
anything in `static/` is served publicly, bundled into the native app
(`build/` → Capacitor), and cached by every web client's service worker.

## How to use

- **Bring one back:** copy it into `static/` where it belonged and reference
  it from code — it will be served/bundled again.
- **Use on marketing pages without bundling:** upload to external hosting
  (CDN / Supabase Storage) and reference the absolute URL instead.
- **Delete freely:** nothing here is referenced by the codebase. This folder
  is just a safe holding pen so good art isn't lost.

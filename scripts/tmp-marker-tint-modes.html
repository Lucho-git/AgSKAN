Marker Tint Modes — side by side

Same icon + colour, three ways of applying it. Switch colour / icon and compare.

Original

Icon colour never changes; circle gets a light tint + strong dark border.
tint_mode: "original"

Circle Fill

Circle carries all the colour right to the edge; middle is white contrast.
tint_mode: "circle-fill"

Icon Fill

Icon carries the rich colour; circle is pure white/grey for contrast.
tint_mode: "icon-fill"

Icon Only

Icon carries the rich deep colour; the circle is removed entirely.
tint_mode: "icon-only"

Icon Dark Glass

Bright icon colour kept; darker translucent glass disc behind it.
tint_mode: "icon-dark-glass"

Icon Light Glass

Light glass disc kept; icon colour darkened to the deep shade.
tint_mode: "icon-light-glass"
This mirrors MarkerManager.tintMarkerCanvas() exactly: each pixel gets a smooth circle-ness factor (greyness × luminance) instead of a hard circle/glyph snap, so the baked anti-aliasing is preserved and edges stay crisp rather than "baked". Circle-fill has no ring, icon-only has no circle at all (transparent), and the glass modes (icon-dark-glass, icon-light-glass) are borderless frosted discs; original strokes the colour's dark ring while icon-fill gets a subtle neutral grey rim, all pulled in so no background peeks through.

# AgSKAN — Copilot Instructions

## Editing Constraints

- **Make small, surgical edits.** Never do a single `replace_string_in_file` larger than ~30 lines. Break work into incremental pieces.
- **Check for errors after every edit.** Run `get_errors` on the edited file before proceeding to the next change.
- **Prefer `multi_replace_string_in_file` for independent edits** across different parts of a file, but keep each replacement small.
- **For Svelte templates:** Add one section at a time, verify `get_errors` passes, then add the next.
- **Svelte templates (`{@const}`, `{#each}`, expressions) do NOT support TypeScript annotations.** Remove `: Type` from any template code.
- **Never use PowerShell for file content operations on UTF-8 files.** Use Node.js or the file tools instead.

## Project Conventions

- **Text colors** use `text-contrast-content` (not `text-base-content`) for dark/light mode compatibility.
- **DaisyUI** handles modal/dialog components (`.modal`, `.modal-box`, `.modal-backdrop`). Don't add custom `.modal-backdrop` CSS — it conflicts.
- **Agworld API:** Proxy at `/agworld-v3-proxy/au/...`. List endpoints lack some fields (`total_area` on operations); fetch individual resources for full data.
